Wheel Speed Control

The goal is to make one Micromouse wheel reach and hold a target speed. The encoder measures the wheel speed, and the controller adjusts the motor PWM duty cycle every sample. The loop is simulated live with our own solver (Euler steps, the same digital PI loop as the Arduino code below).

1. Plant model and its source

Apply a PWM step between two fixed duty levels and log encoder speed. Use steady speeds y0 before the step and y1 after it, and express duty as a fraction from 0 to 1. Compute K = (y₁ − y₀) / (d₁ − d₀). Read τ as the time from the PWM step until the speed first reaches y₀ + 0.632(y₁ − y₀). Enter the measured values below using normalized speed.

2. Spec and why it matters

The wheel must reach a speed command of (normalized) quickly, without overshooting, and then hold it. Each wheel has to track its command so the robot drives a predictable path through the maze.

The numbers in the spec table are checked live against the simulation. They were set while the motor is still a placeholder, so revisit them after the real measurement.
