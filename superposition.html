Bonus 2: Superposition

Build an input from two or three sine waves and see how a first-order sensor changes the combined waveform.

Model

τ dy/dt + y = x(t), with static gain K = 1.

x(t) = Σ Aᵢ sin(ωᵢt)
yss(t) = Σ Aᵢ Mᵢ sin(ωᵢt + φᵢ)
Mᵢ = 1/√[1 + (ωᵢτ)²], φᵢ = −atan(ωᵢτ)

These are steady-state responses after the transient has decayed. The output need not start at zero. Frequencies are in rad/s. Superposition means the response to the sum equals the sum of the individual responses.

Predict, then check

For two input components of equal amplitude but different frequencies, which has the smaller output amplitude?
